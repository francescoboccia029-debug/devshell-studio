# DevShell Studio — sito statico per GitHub Pages

Sito vetrina responsive in HTML, CSS e JavaScript vanilla. Non richiede framework, build o servizi a pagamento.

## File
- `index.html`: sito completo.
- `assets/`: illustrazioni SVG locali e favicon. Le immagini sono incluse nel repository, quindi non dipendono da host esterni e funzionano anche offline.
- `README.md`: queste istruzioni.

## Pubblicare gratuitamente con GitHub Pages
1. Crea o accedi a un account su https://github.com/.
2. Premi **+** in alto a destra → **New repository**.
3. Nome suggerito: `devshell-studio`. Se usi GitHub Free, imposta il repository su **Public**.
4. Crea il repository. Se scegli di aggiungere un README durante la creazione, va bene.
5. Nella pagina del repository premi **Add file → Upload files**.
6. Estrai lo ZIP sul computer e carica i file e la cartella `assets` direttamente nella radice del repository. Importante: `index.html` deve stare nella radice, non dentro una seconda cartella `devshell-studio-github`.
7. Premi **Commit changes**.
8. Apri **Settings → Pages**.
9. In **Build and deployment**, seleziona **Deploy from a branch**.
10. Seleziona branch `main`, cartella `/(root)`, poi **Save**.
11. Attendi qualche minuto e riapri la sezione Pages: troverai l'indirizzo pubblico del sito, generalmente `https://TUO-USERNAME.github.io/devshell-studio/`.

Guida ufficiale: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Contatti
L'indirizzo impostato è `devshellstudiohelp@gmail.com`. Il modulo prepara una bozza tramite `mailto:`: il visitatore deve avere un'app email configurata e premere invio. Non è un modulo con invio diretto lato server.

## Modifiche
Puoi modificare `index.html` direttamente su GitHub cliccando sul file e poi sulla matita, oppure lavorare con VS Code e ricaricare i file. Dopo ogni commit, GitHub Pages aggiorna il sito automaticamente (può volerci qualche minuto).
